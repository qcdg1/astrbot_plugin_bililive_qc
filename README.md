# astrbot_plugin_bililive_qc

bilibili上下播通知（B 站开播 / 下播提醒，**免登录**，支持卡片式通知）

## 使用方法

在 AstrBot 插件配置页填写 `rooms`，每行一个直播间：

```
房间号|自定义昵称|群号1|群号2|群号3
```

例如：

```
21987615|某主播|123456789|987654321
21452505|另一个主播|555555555
```

- **房间号**：直播间地址里的那串数字，见下方说明
- **自定义昵称**：群消息正文里"xxx 开播啦！"显示的名字（留空则显示"主播"）；
  卡片上不显示它，卡片上优先显示主播的 B 站真实昵称
- **推送群号**：**该主播通知推送到哪些群**，可写多个，用 `|` 隔开。
  也兼容逗号 `,` / 中文逗号 `，` / 顿号 `、` / 空格。
  不同主播可以配置完全不同的推送群，互不影响。
  这个群列表同时决定 `liveinfo` 指令在该群里能看到哪些主播

直播间房间号获取方式：

```
https://live.bilibili.com/21987615
                        房间号:^^^
```

### 推送功能

自动触发。指定直播间开播 / 下播后会在**配置给该主播的群**内发一条消息。

开播通知长这样：

```
主播昵称 😋 开播啦！
https://live.bilibili.com/21987615
[一张卡片图]
```

卡片图是一张白色圆角卡片，顶部是**圆形头像 + 主播的 B 站昵称**（昵称紧挨头像右侧、垂直居中），
往下依次是直播标题、直播间封面（圆角 16:9）、LIVE 状态/分区标签、
累计观看、主播粉丝、房间号和开播时间。

- **主播头像**：免登录从 `get_info` 的 `face` 字段获取，裁成圆形显示；取不到时画一个粉色占位圆
- **B 站昵称**：直接显示在头像右边。卡片上**不写**"开播啦"和你在 `rooms` 里配的自定义备注名
  （这两者群消息正文已经带了）；只有取不到 B 站昵称时，才退回显示配置的备注名
- 卡片底部只保留开播时间，**不再重复**直播间地址（正文里已经发了链接）

下播通知长这样：

```
主播昵称 💤 下播啦！
[一张长条图]
```

下播长条图一行搞定，**浅灰底色**（开播卡片是白底，方便一眼区分），显示：

- 圆形头像
- 第一行：`备注名称 | 直播标题`
- B 站昵称 · 累计观看 · 粉丝数
- `开播：xxx    下播：xxx`（同一行）
- `本次直播时长：xxx`
- 右侧「未开播」状态药丸

- 下播时接口已经拿不到标题/头像了，所以这些信息在**开播那一刻就缓存下来**，下播时复用
- 开播时间取不到时显示「未知」，直播时长也显示「未知」

### 查询功能

```sh
liveinfo
```

输出所有直播间的「名称 | 状态 | 直播间链接」，每个主播一段；
同时会在末尾附上一张**长条信息图**（一行一个主播），只显示：

- 圆形主播头像
- 第一行：`备注名称 | 直播标题`（标题过长自动截断加省略号）
- 第二行：B 站昵称 · 累计观看 · 粉丝数（取不到 B 站昵称时退回配置昵称）
- 右侧状态药丸（直播中 / 未开播 / 轮播中）

**按群隔离**：在群里发指令时，只会显示「推送群包含本群」的主播，
不会泄露其他群的主播配置。

```
青菜冬瓜 | 😋 直播中
https://live.bilibili.com/31023403

星悦 | 💤 未开播
https://live.bilibili.com/1789072103
```

- 私聊里发指令不受限制，显示**全部**主播
- 本群没有配到任何主播时，会提示先到 `rooms` 里补上本群群号

`render_card` 关闭时不渲染长条图，只发文字。长条图渲染失败也会自动退回纯文字，指令始终可用。

### 只发长条图

```sh
livelist
```

和 `liveinfo` **完全一样**（同样按群隔离、同样渲染长条图），区别是**只发图、不带文字**。
适合消息多、只想瞄一眼状态的场景。

```
[一张长条信息图]
```

> 图没渲染出来时（`render_card` 关闭或渲染异常），会退回发文字版并加一句提示，
> 不会出现「指令发出去却什么都没回」的情况。

### 查看全部（管理员）

```sh
liveinfoall
livelistall
```

**仅管理员可用**，忽略本群限制、显示**所有**主播：

| 指令 | 输出 |
| --- | --- |
| `liveinfoall` | 文字 + 长条图（同 `liveinfo` 格式） |
| `livelistall` | 只发长条图（同 `livelist` 格式） |

非管理员发送会得到 `⚠️ 该指令仅管理员可用。`

管理员身份判定顺序：

1. 事件对象自带的 `is_admin()` / `is_super_user()`
2. AstrBot 的超管列表（`context.get_super_user_ids()`）
3. 兜底：消息发送者 ID 在插件配置的 `admins_id` 里

> 说明：之所以单独做一个 `liveinfoall` 而不是 `liveinfo all`，是因为 AstrBot 的
> `@filter.command("liveinfo")` 对**带子参数**的消息匹配行为在不同版本间不一致，
> 拆成独立指令最稳。

### 清空缓存

```sh
livers
```

清空开播状态缓存，强制下一轮重新识别状态（调试用）。

## 指令一览

| 指令 | 权限 | 输出 | 范围 |
| --- | --- | --- | --- |
| `liveinfo` | 所有人 | 文字 + 长条图 | 本群相关（私聊=全部） |
| `livelist` | 所有人 | 只发长条图 | 本群相关（私聊=全部） |
| `liveinfoall` | 仅管理员 | 文字 + 长条图 | 全部主播 |
| `livelistall` | 仅管理员 | 只发长条图 | 全部主播 |
| `livers` | 所有人 | 文字 | 清空开播状态缓存 |

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `rooms` | list | — | 直播间配置，格式见上 |
| `check_interval` | int | 300 | 轮询间隔（秒），建议不低于 60 |
| `admins_id` | list | 空 | `liveinfoall` 的管理员判定兜底名单（一般用不到，优先用 AstrBot 自带权限） |
| `render_card` | bool | true | 是否渲染合成图：开播通知的卡片、`/liveinfo` 的长条图。关闭则只发文字 |
| `font_path` | string | 空（自动探测） | 卡片中文字体路径 |
| `emoji_font_path` | string | 空（自动探测） | 卡片 emoji 字体路径 |

## 依赖

- `pillow`（渲染卡片必需）。未安装时自动降级为「文字 + 原始封面图」。
- 中文字体：
  - Windows 自动使用 `C:\Windows\Fonts\msyhbd.ttc`，emoji 用 `seguiemj.ttf`，无需配置
  - Linux 需安装 `fonts-noto-cjk`；emoji 需 `fonts-noto-color-emoji`，否则卡片中文会显示为方块
  - 也可在配置里手动填 `font_path` / `emoji_font_path`

## 数据来源

卡片信息全部来自 B 站**免登录**接口，无需 Cookie：

| 来源 | 取用字段 |
| --- | --- |
| `room/v1/Room/get_info` | 标题、封面、主播头像 `face`、开播状态、开播时间、分区、人气值、累计观看 |
| `x/relation/stat` | 主播粉丝数 |
| `live_user/v1/Master/info` | 主播昵称 `uname`、头像 `face`（上一接口缺失时兜底，非每次请求） |

请求会带上自动获取的 `buvid` Cookie；遇到 412 风控会自动重取并重试一次。
